# Calcora

Static US calculator website built with HTML, CSS and JavaScript.

## Free deployment
1. Create a GitHub account.
2. Create a public repository named `YOURUSERNAME.github.io`.
3. Upload everything in this folder.
4. In Settings → Pages, publish from the `main` branch/root.
5. Replace `https://calcora.github.io/` in canonical URLs and sitemap with the real live URL.

## Before AdSense
- Replace the placeholder contact email.
- Replace the placeholder canonical domain.
- Review the Privacy Policy for the exact analytics/advertising/cookie setup.
- Add substantial original content to important calculator pages.
- Test every calculator on desktop and mobile.
- Create and verify the site in Google Search Console.
- Submit the sitemap.
- Apply for AdSense only once the site is live, complete and useful enough for review.
