Contact Calcora

We welcome reports of calculator errors, broken links, accessibility issues and general feedback.

How to contact us

For now, the simplest way to contact the project is through the public GitHub repository where Calcora is maintained.

Open Calcora on GitHub

What to include

If you report a problem with a calculator, include the calculator name, the inputs you used, the result you expected and a short description of the issue. Please do not include sensitive personal information.
